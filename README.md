# first_stream_java

Пет-проект: консольный калькулятор на Java.

`Calc.main` работает пошагово через `Scanner`:

1. **Приветствие** — спрашивает имя; пустое имя (или имя из пробелов) даёт `Привет, гость!`, для `Иван` дополнительно печатает `Давно не виделись!`.
2. **Выбор операции** — `0` (сложение) или `1` (вычитание); любой другой ввод вызывает повторный запрос.
3. **Два целых числа** — читаются через `readInt()`: мусор (буквы, дробные) или число вне диапазона `int` выводят `Ошибка: число вне допустимого диапазона` и запрашивают значение заново, без падения.
4. **Результат** — `Сумма чисел = <результат>` или `Разность чисел = <результат>`.

## Требования
- Java 17
- Gradle-обёртка 9.6.0 (используйте `./gradlew`, системный `gradle` не нужен)

## Запуск
Плагин `application` подключён (`mainClass = 'Calc'`), поэтому:

```bash
./gradlew run      # интерактивный запуск в терминале
```

Готовый `run` не прокидывает piped stdin во forked-процесс, поэтому `printf '...' | ./gradlew run` не сработает — вводите данные вживую. Для скриптового запуска соберите и запустите класс напрямую:

```bash
./gradlew build
java -cp build/classes/java/main Calc   # сюда можно подавать stdin пайпом
```

## Тесты
```bash
./gradlew test                                      # все тесты
./gradlew test --tests CalcTest                     # один класс
./gradlew test --tests CalcTest.testGreetingWithName  # один метод
./gradlew test -PincludeTags=smoke                  # только smoke-тесты
```

Тесты построены на JUnit 5 и подменяют `System.in`/`System.out`, чтобы управлять вводом и проверять вывод `Calc.main`.
