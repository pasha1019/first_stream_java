# first_stream_java

Пет-проект на Java: консольный калькулятор и несколько учебных примеров.

## Структура
- `src/main/java/Calc.java` — калькулятор (приветствие, выбор операции, два числа, результат).
- `src/main/java/ConvertFeetInches.java` — таблица «дюймы → метры» от 1 до 100.
- `src/main/java/GalToLitTable.java` — таблица «галлоны → литры» от 1 до 100.
- `src/main/java/Weight0nMoon.java` — пересчёт веса с Земли на Луну.
- `src/test/java/CalcTest.java` — JUnit 5-тесты для `Calc`.

## Калькулятор

`Calc.main` работает пошагово через `Scanner`:

1. **Приветствие** — спрашивает имя; пустое имя (или имя из пробелов) даёт `Привет, гость!`, для `Иван` дополнительно печатает `Давно не виделись!`.
2. **Выбор операции** — `0` (сложение) или `1` (вычитание); любой другой ввод вызывает повторный запрос.
3. **Два целых числа** — читаются через `readInt()`: буквы (например `abc`) дают `Ошибка: "abc" не является числом`, а дробные числа или числа вне диапазона `int` — `Ошибка: число вне допустимого диапазона`; в обоих случаях значение запрашивается заново, без падения.
4. **Результат** — `Сумма чисел = <результат>` или `Разность чисел = <результат>`. Сумма и разность считаются в `long`, поэтому переполнение `int` не ломает результат (см. «Переполнение»).

### Переполнение
Сумма и разность вычисляются в `long`: `long sum = (long) a + b;`. Поэтому `2147483647 + 1` даёт `2147483648`, а не `-2147483648`, как было бы при обычном сложении `int` (там переполнение «переносится» и даёт `Integer.MIN_VALUE`).

Дополнительно `Math.addExact` / `Math.subtractExact` используются как детектор переполнения: если результат не помещается в `int`, печатается предупреждение, но сам результат всё равно выводится и программа не падает.

```
Введите первое число: 2147483647
Введите второе число: 1
Внимание: Сумма чисел не помещается в int, результат вычислен в long
Сумма чисел = 2147483648
```

## Учебные примеры
- **`ConvertFeetInches`** — печатает таблицу от 1 до 100 дюймов и соответствующие метры; каждые 12 строк вставляется пустая строка, чтобы группы таблицы читались отдельно.
- **`GalToLitTable`** — печатает таблицу от 1 до 100 галлонов и соответствующие литры; пустая строка вставляется каждые 10 строк.
- **`Weight0nMoon`** — спрашивает вес на Земле (кг) и печатает вес на Луне: сила притяжения там примерно в 6 раз меньше, поэтому вес равен 17% земного.

## Требования
- Java 17
- Gradle-обёртка 9.6.0 (используйте `./gradlew`, системный `gradle` не нужен)

## Запуск
Плагина `application` в проекте нет, поэтому задачи `./gradlew run` не существует. Соберите проект и запустите нужный класс напрямую:

```bash
./gradlew build
java -cp build/classes/java/main Calc                # калькулятор — ввод с клавиатуры
java -cp build/classes/java/main ConvertFeetInches    # таблица дюймов в метрах
java -cp build/classes/java/main GalToLitTable        # таблица галлонов в литрах
java -cp build/classes/java/main Weight0nMoon         # вес на Луне
```

Примеры, где нужен ввод, можно запускать с пайпом:

```bash
printf '70\n' | java -cp build/classes/java/main Weight0nMoon
```

## Тесты
```bash
./gradlew test                                      # все тесты
./gradlew test --tests CalcTest                     # один класс
./gradlew test --tests CalcTest.testGreetingWithName  # один метод
./gradlew test -PincludeTags=unit                   # только unit-тесты
```

Тесты построены на JUnit 5 и подменяют `System.in`/`System.out`, чтобы управлять вводом и проверять вывод `Calc.main`. Покрыт только `Calc`; учебные примеры тестами не проверяются.
